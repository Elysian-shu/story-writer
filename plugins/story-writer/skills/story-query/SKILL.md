# 查询与复盘

用 `query [--unit N] [--term 关键词]` 查询有效事实；history 查询完整历史，doctor 检查来源与事务。作者视图含机密，读者视图与起草不得直接复制完整结果。

回答每项事实的 ID、来源和状态；未知不补全。复盘承诺时用真实记录解释进展与未回收，不声称脚本已自动实现承诺债算法。人物口供、记忆和客观事件区分回答。

`dashboard --out 导出/账本-新版本.html` 保存私人静态快照。它不会实时更新，也不启动公网服务；资料变更后生成新快照，不覆盖已有作者文件。
