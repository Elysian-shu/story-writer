# Story Writer 总控

先读 [工作流](../../references/workflow.md)。工具入口为插件根目录 `scripts/story.py`，参数列表调用 `python <入口> --book <书仓> <命令>`；不得将作者文本拼入 shell。

1. 先读实际目录与 `doctor/query/history`，不得把上一轮聊天总结当正史。
2. 未有书仓先立项；初始化仅限空目录，书仓与插件代码分开。当前 cloud task 已隔离，使用现有目录，不创建 Git worktree。
3. 分别处理来源、候选、有效设定、草稿及定稿。写作的核心新设定与入档依据真实作者授权；先做成具体可审阅成果，不重复确认已授权内容。
4. 普通备料、起草、检查与诊断持续推进；只在素材缺失、创作方向冲突或当前事实入档未授权时提问。
5. 需要用其他技能时按任务读对应说明；不自动启动子代理或外部模型。审读分轮进行，同会话无独立上下文时说明局限。
6. 暂停前生成书仓 ZIP；恢复新包用 restore 到新目录，拒绝覆盖、路径逃逸与来源完整性错误。
7. 私人使用：不推送仓库、不公开发布、不部署外部服务、不传输稿件；只提供当前授权的本地成果。ChatGPT 可见性由用户设为仅我可见，未实际核验不能声称设置成功。

最终报告包括真实成果、阻断/局限、实际文件与下一步；不把测试夹具或未运行命令当成功证据。
