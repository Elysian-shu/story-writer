# 立项与接入

读 [数据协议](../../references/data-contract.md) 的作品配置、来源和事实提案部分。

围绕当前任务收集必要的书名、形式、主题、视角、文风、禁区、篇幅与作者已有内容。能合理默认的结构直接执行；未确认的结局和设定留候选，不制造既有资料。

`init --title ... --format ... --units ... --unit-label ... --segment-label ...` 创建空书仓。作者构想本身可作为来源；`import-source → propose` 先保存可核对材料，再呈现作者确认范围，依据真实授权 accept。相互矛盾的资料列为决策项，不自动把新版或多数说法当正确。

PDF/EPUB/DOCX 当前需另外转换与原件核对，不能声称引擎直接支持。所有文件私人保存，不调用外部转换/模型服务。只按需准备故事骨架，不强迫短篇填完长篇世界书。
