# 写作闭环

读 [工作流](../../references/workflow.md) 的命令顺序与 [数据协议](../../references/data-contract.md)。

核对当前段号、原稿与授权范围。合同和 brief 通过后，在工作区/草稿保存完整正文；作者手改不覆盖，新版本另存。根据形式选择散文、动作对白或分镜，不把系统流程写进故事。

起草只使用可披露包；人物获得信息须有途径。新增设定留候选，不自行污染正史。check→真实八维审读→review→修改→重审。提取事实与真实摘要后，将正文、问题与事实变更呈现给作者；按真实授权 settle，不伪造 author/note。

定稿后 doctor、query、backup 交付。只完成本次授权的段落，不擅自批量续写。本技能不自动派发代理；同会话审读轮次不构成独立上下文。
