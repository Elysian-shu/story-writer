# 审读

读 [八维协议](../../references/data-contract.md) 与 [题材适配](../../references/genre-profiles.md)。运行 check 取得当前稿 fingerprint 和实际计数，然后重新阅读完整正文、合同与作者账本。

机检与语义审读分别报告，缺材料或缺结论写 unknown。每维包括本稿原句、明确结论、理由与发现项。合同目标、人物动机、信息来源、因果和题材公平性必须实际核对，不能仅输出“通过”。不适用维度解释为何。

review 保存当前报告，任何 block/unknown/open 阻止定稿。改稿或约束变化后重审；不得把旧证据换上新哈希来骗过版本检查。新修订保守列出定稿范围后由作者/真实审读核对；不修改冻结正文。真实审读与测试 fixture 严格分开。
