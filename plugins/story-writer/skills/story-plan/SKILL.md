# 规划

读 [形式适配](../../references/genre-profiles.md) 和 [数据协议](../../references/data-contract.md) 的章合同部分。

先 query 有效设定，明确主线目标、选择、代价、人物变化、信息披露和承诺回收。规划与已发生事实分开。主题、结局或核心动机有新方向时做候选；在既有授权范围内完成具体细纲。

contract 必须引用有效事实；unit 是组织单元，chapter 是全书连续段号。读者与视角人物知情分别处理。allowed_new_entities 只登记被本次授权允许的新对象。reveal_fact_ids 不自动扩大到所有机密。

无固定 60/20/20 比例，无强制每段反转或新增人物。让形式与作者要求决定结构，保存合同后执行 brief 验证可用性。
