# 形式与题材适配

这是审读与备料策略，不是强制剧情模板，也不作为作者既定设定。profile 文本进入作品配置、备料与 GPT 语义审读；脚本不假装自动理解题材。

| 形式/侧重 | 单元 / 段的建议 | 重点审读 | 不强制 |
|---|---|---|---|
| 长篇小说 | 卷 / 章 | 人物弧线、伏笔债、跨卷因果、连续性 | 每章反转或固定爽点密度 |
| 短篇小说 | 篇 / 节 | 整体经济性、有限人物、收束与余韵 | 分卷、宏大世界书 |
| 剧本 | 幕 / 场 | 场景目标、可表演动作、对白功能、场间因果 | 以心理独白交代全部冲突 |
| 漫画脚本 | 话 / 场 | 画面信息、分镜动线、对白负担 | 纯散文叙述 |
| 悬疑推理 | 案/卷 / 章 | 真相链、侦查链、证词可靠性、公平线索、知情差 | 提前用作者机密制造角色全知 |
| 爱情/关系故事 | 阶段/卷 / 章 | 双方选择、关系变化、情感代价、互动节奏 | 固定“火线”比例 |
| 奇幻/科幻 | 卷/幕 / 章/场 | 规则边界、能力代价、信息来源、因果后果 | 照搬升级爽文节奏 |
| 儿童故事 | 篇 / 节 | 年龄适宜、可理解动机、清晰因果与情绪安全 | 成人化表达、说教结论 |
| 文学/实验叙事 | 部 / 节 | 视角策略、语言自洽、主题张力与结构意图 | 线性时间或商业钩子 |
| 纪实/回忆叙事 | 阶段/篇 / 节 | 来源可追溯、事实与重构区分、记忆不确定性 | 把想象当史实 |

八个审读维度统一保留，但解释随形式变化：非悬疑的“线索伏笔”可检查意象呼应；无悬念的“读者承诺”可检查情绪/主题期待。判定不适用时说明作品依据，不为了完成表格发明要求。

每个世界书事实可用 `known_since` 记录“谁从第几段开始知道”；`reveal_at: null` 表示作者机密。精确字符串机检只会抓到部分显式泄密；改写、暗示、反讽、非可靠叙述必须依靠语义审读。

全知叙述可将 pov 标为“全知叙述者”，再由作者合同明确披露；不自动把全部机密开放。剧本中多个视角或群像场景应在合同目标和语义审读中说明各人物所知；本版没有自动对白说话人解析。
